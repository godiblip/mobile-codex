# Mobile Codex 0.2.13

- Codex Live 음성 대화를 추가했습니다. 기존 계정으로 프로젝트 작업을 말로 지시하고 결과를 음성으로 들을 수 있습니다.
- 음성 크기에 반응하는 원, 마이크 음소거, 대화 종료, 음성·언어 설정을 제공합니다.
- 음성 25개를 접고 펼치는 선택창에 표시합니다. 확인된 한국어·미국 영어·독일어 음성을 묶고, 한국어 음성은 한울·햇살로 표시합니다. 나머지는 기타에 표시합니다.
- 모델 선택기를 정리하고 추론 강도를 영어로 표시합니다. 작업 권한은 모델 선택기의 작업 권한 메뉴로 모았습니다.
- 기존 서명으로 업데이트하며 로그인과 대화 기록을 유지합니다.

현재 Live 안에서 글로 보낸 작업 지시는 말로만 응답하고 실행되지 않을 수 있습니다. 작업 지시는 음성이나 일반 채팅 입력창을 사용하세요.
