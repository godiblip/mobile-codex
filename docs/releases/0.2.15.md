# Mobile Codex 0.2.15

- Codex Live를 Android 네이티브 음성 처리로 전환해 백그라운드에서 자막만 나오고 소리가 멈추는 문제를 개선했습니다.
- Android 12 이상에서 통화 중 표시, 통화 시간과 종료 버튼이 있는 시스템 통화 알림을 사용합니다. 표시 형태는 기기에 따라 다릅니다.
- 알림에서 음성을 종료한 뒤 앱으로 돌아오면 종료 상태를 정확히 표시하며 다시 연결할 수 있습니다.
- 기존 서명으로 업데이트하며 로그인, 대화 기록과 프로젝트 권한을 유지합니다.

---

- Codex Live now uses native Android audio to improve background playback when captions continue but sound stops.
- Android 12 and later use a system ongoing-call notification with elapsed time and an End action. Indicator appearance varies by device.
- Returning after ending voice from the notification shows the correct ended state and allows reconnection.
- Updates retain the original signing certificate, login, chat history, and project permissions.
