# Mobile Codex 0.2.11

## 한국어

- 단체 대화에서 이미 답한 참가자의 후속 멘션이 무시되던 문제를 수정했습니다. Claude가 마지막에 `@codex`로 부르면 Codex가 새 답변들을 읽고 이어서 응답합니다.
- 현재 응답들이 모두 끝난 뒤 후속 호출을 실행합니다. 여러 참가자가 같은 상대를 부르면 한 번으로 합칩니다.
- 자기 호출·같은 상대에 대한 반복 호출 방지, 호출 깊이·전체 발언 횟수 제한, 중지와 사용자 개입 동작은 유지합니다.

## English

- Fix follow-up mentions being ignored when the recipient had already answered. When Claude calls `@codex` in its final reply, Codex reads the new answers and responds again.
- Wait for the current replies to finish before running follow-ups, merging requests for the same participant into one response.
- Retain self-call and repeated-call prevention, depth and turn limits, Stop and user intervention behavior.
