# Mobile Codex 0.2.8

## 한국어

- **에이전트 초대:** 기존 Codex 대화의 `+ → 에이전트 초대`에서 Claude와 Gemini(Antigravity)를 초대합니다. 참가자 멘션, 순차 답변, 참가자별 모델·추론·권한 설정을 제공합니다.
- **같은 대화에서 이어가기:** 참가자는 앞선 답변을 읽고 이어서 답합니다. 참가자와 공급자 세션을 저장하며, 중지와 사용자 개입 시 대기 중인 발언을 취소합니다.
- **설치·로그인:** 계정 설정에서 Claude·Antigravity CLI를 설치하고 로그인합니다. 설치 질문과 인증 코드 입력, 터미널 색상 조회 처리, Claude 설치 다운로드 경로를 개선했습니다.
- **Codex 런타임:** `@mmmbuto/codex-cli-termux@0.162.1-termux.1`로 갱신했습니다. 모델·추론 선택은 공급자가 반환하는 실제 목록을 사용합니다.
- **화면 정리:** Chat 전환, Pro에게 물어보기, GitHub 프로젝트 동기화와 음성 입력 후 전송 안내를 제거했습니다. 기존 파일·첨부·승인·플로팅 대화와 프로젝트 JSON 이전은 유지합니다.

Claude·Antigravity는 앱 내부 Linux 환경에서 실행하며 별도 PC 서버나 외부 Termux 앱은 필요하지 않습니다. 로그인·모델 접근은 각 공급자 계정에 따릅니다. 실제 Android CLI 실행·OAuth 복귀·계정별 AI 응답은 자동 검사만으로 검증되지 않습니다. [사용 및 기기 확인 안내](../invited-agents.md)를 참고하세요.

## English

- **Invite agents:** Add Claude and Gemini (Antigravity) through `+ → Invite agents` in an existing Codex chat. Use participant mentions, sequential replies, and individual model, reasoning and permission settings.
- **Continue the conversation:** Participants read earlier replies. Participant and provider session state persists; stopping or intervening cancels pending replies.
- **Installation and login:** Install and sign in to the provider CLIs from Account settings. Improve installer answers, authentication-code input, terminal color queries and the Claude installer download path.
- **Codex runtime:** Update to `@mmmbuto/codex-cli-termux@0.162.1-termux.1`. Model and reasoning options come from each provider's actual list.
- **Simpler interface:** Remove Chat mode switching, Ask Pro, GitHub project sync and the dictation send reminder. Keep files, attachments, approvals, floating chat and project JSON transfer.

Claude and Antigravity use the in-app Linux environment; no separate PC server or external Termux app is required. Login and model access depend on each provider account. Automated tests do not establish actual Android CLI execution, OAuth return handling or authenticated model responses. See the [usage and device checklist](../invited-agents.md).
