## 한국어

- Claude와 Gemini(Antigravity)의 참가자 설정에 승인 방식을 추가했습니다. 수동 승인·모두 허용을 선택할 수 있고, Claude는 설치된 CLI가 지원할 때 자체 자동 검토를 사용합니다. 지원하지 않는 자동 검토는 표시하지 않습니다.
- 모두에게 보내면 Codex·Claude·Gemini가 동시에 응답을 시작하고, 답변이 처음 도착하는 순서대로 표시됩니다. 후속 멘션은 해당 차례의 답변을 모두 읽고 이어집니다.

- 참가자별 승인 설정과 대화 문맥을 저장하고 복원합니다. 기존 읽기 전용·프로젝트 범위·휴대폰 제어 권한은 유지합니다.
