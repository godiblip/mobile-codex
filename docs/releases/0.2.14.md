# Mobile Codex 0.2.14

- 다른 앱으로 전환하거나 화면을 꺼도 Codex Live 음성 대화가 이어집니다.
- Codex Live 알림에서 대화로 돌아가거나 음성 연결을 종료할 수 있습니다.
- 음성 종료 시 마이크와 백그라운드 음성 서비스를 해제하며 진행 중인 Codex 작업은 유지합니다.
- 기존 서명으로 업데이트하며 로그인과 대화 기록을 유지합니다.

---

- Codex Live continues when switching apps or locking the screen.
- Return to the call or end voice from the Codex Live notification.
- Ending voice releases the microphone and background audio service without cancelling ongoing Codex work.
- Updates retain the original signing certificate, login, and chat history.
